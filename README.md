# Basic Stock Market Trend Analysis 📈

A beginner-friendly Python project using Jupyter Notebook to explore historical stock prices.

## What it does
- Downloads stock prices with `yfinance`
- Removes missing closing-price values
- Calculates 20-day and 50-day moving averages
- Plots stock prices and moving averages
- Displays first, latest, highest, and lowest closing prices

## Tools
Python, Jupyter Notebook, pandas, Matplotlib, yfinance

## How to run
1. Install Python and Jupyter Notebook.
2. Open a terminal and run:
   ```bash
   pip install notebook yfinance pandas matplotlib
   jupyter notebook
   ```
3. Open `Basic_Stock_Market_Trend_Analysis.ipynb`.
4. Run each cell from top to bottom.
5. Internet access is required to download market data.

The example uses Apple (`AAPL`). You can replace `AAPL` in the download cell with another supported ticker, such as `MSFT`, `GOOGL`, `RELIANCE.NS`, or `TCS.NS`.
